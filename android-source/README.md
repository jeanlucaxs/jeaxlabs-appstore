# JeaxLabs OS v1.0.0 — build inicial

Projeto Android inicial para Samsung Galaxy Tab A7 Lite LTE SM-T225. Este build é um protótipo de interface: não é ROM, não ativa Device Owner sozinho e ainda não implementa a loja .jxa, atualizador .jxu, kiosk completo, central de notificações própria ou controles privilegiados.

O GitHub Actions compila o APK de debug e publica um ZIP com o APK e o código-fonte como artefato da execução.
