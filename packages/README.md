# JeaxLabs Store — packages

Envie aqui os aplicativos públicos empacotados no formato `.jxa` para que apareçam na JeaxLabs Store.

- Use **Add file → Upload files** para enviar o arquivo `.jxa`.
- Não é necessário adicionar ou editar um JSON de catálogo.
- O APK JeaxLabs OS precisa incluir a mudança que aponta o catálogo para este repositório para listar os arquivos daqui.
- Este repositório é público; qualquer arquivo enviado aqui poderá ser baixado publicamente.
